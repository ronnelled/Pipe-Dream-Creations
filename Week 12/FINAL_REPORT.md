# Pipe Dream Creations Final Report

## Project Overview
Pipe Dream Creations is a small business website for handmade pipe 
cleaner creations. The website includes a homepage, about page, products page,
contact page, FAQ page, navigation, branding, accessibility improvements, and 
deployment through GitHub Pages.
