## Setup Instructions
1. Open the repository in GitHub
2. Review the README.md file.
3. Open index.html to view the homepage.
4. Use GitHub Pages to publish the site.
5. Use GitHub Actions to confirm the workflow passes.

## Credentials Process
No passwords, API keys, or private credentials should be stored in the repository.

If credentials are needed in the future:
1. Go to GitHub repository Settings.
2. Click Secrets and variables.
3. Click Actions.
4. Add credentials as repository secrets.
5. Never place credentials directly inside HTML, CSS, JavaScript, or Markdown files.
