# Final Presentation Script

## Introduction
Hello, my name is Ronnelle, and this is my final project presentation for Pipe Dream Creations.

## Project Purpose
Pipe Dream Creations is a small business website designed to showcase handmade pipe cleaner creations. The purpose of the website is to help customers learn about the business, view products, and contact the owner.

## Main Features
The website includes a homepage, about page, products page, contact page, and FAQ page. It also includes shared navigation, responsive styling, accessibility improvements, and basic documentation.

## Development Process
The project was built over multiple weeks. I started with planning and user stories, then created wireframes, architecture documentation, front-end pages, testing evidence, documentation, and final release materials.

## Security, Accessibility, and Performance
For the final check-in, I reviewed the project using OWASP security testing ideas, accessibility best practices, and Lighthouse performance evidence. I checked for exposed credentials, clear page structure, readable navigation, and lightweight static files.

## Final Release
The final version is published using GitHub Pages. The repository includes the final report, handoff package, setup documentation, and known issues.

## Retrospective
One success of this project was building a complete multi-page website from planning through release. One challenge was learning how to organize GitHub files, workflows, and documentation. In the future, I would improve the contact form and add more automated tests.
